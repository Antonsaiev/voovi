Учётные данные перенесены из старого окружения в общие `configs/env/local.env`

## Передача и импорт

Firefox пишет в `var/bank/downloads/staging`. После стабилизации проверяются формат
1С, окончание файла, расчётный счёт и обе даты периода. Файл атомарно публикуется в
`var/bank/downloads/ready`, оригинал сохраняется в `archive`, подтверждение — в `state`.
Недописанные и неверные файлы во входную папку импортёра не попадают.

Прежний общий worker плавно остановлен с кодом 0 до переключения каталогов.

в проект; прежние каталоги сохранены. Подготовленные файлы теперь находятся
в `var/bank/file_for_process`. Прежняя папка ручных загрузок старой аналитики
остаётся дополнительным источником существующего импортёра.
