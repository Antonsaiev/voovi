# Автосохранение полей ЭЦП

- Владелец сертификата сохраняется при выборе, адрес — через 600 мс после ввода и при потере фокуса. Кнопки сохранения/отмены убраны, адрес всегда доступен для редактирования в многострочном поле.
- При скрытии страницы и pagehide отправляется последнее значение через sendBeacon (fallback fetch keepalive), даже если поле не теряло фокус.
- Каждый ввод сразу оставляет черновик в localStorage, отдельно по пользователю/счёту/полю. Подтверждённое сохранение удаляет черновик. После повторного открытия он восстанавливается и отправляется, при возвращении сети выполняется повторная попытка.
- Браузер не гарантирует доставку при аварийном завершении или отсутствии сети. Поэтому неполученные сервером изменения сохраняются черновиком, а успешный статус ставится только после ответа сервера.
- Поля сохраняются отдельными POST-запросами с существующей авторизацией и подписанным токеном. Никаких внешних сервисов и изменений структуры базы.
- Сервер разрешает только schet.vladelec / schet.fadress, проверяет связь владельца с клиентом и обновляет действующие строки rand в транзакции. Проверка предыдущего значения защищает от запоздавших запросов и одновременных правок. Пустой адрес также сохраняется.
- JS: js/invoice-fields-autosave.js. Сервер: invoice_fields.php и invoice_fields_storage.php. В komnete.php заменены прежние обработчики и кнопки только этого блока.
- Проверки: 4 JS-теста (очередь, возврат к исходному значению/очистка, ошибка сети, pagehide без blur); PHP-тест в voovi_invoice_manager_test (несколько строк, чужой контакт, устаревший запрос, очистка, повтор). PHP lint и прежние проверки отображения прошли. В браузере проверен блок без кнопки и отсутствие ошибок JS. Production не изменялся.
