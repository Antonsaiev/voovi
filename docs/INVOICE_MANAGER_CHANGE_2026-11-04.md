# Смена менеджера счёта

В карточке komnete.php добавлена кнопка с карандашом рядом с «Счёт выставил». Доступна только активному авторизованному пользователю с users.adm=1. Этот существующий признак даёт максимальные права администрирования; otvetstven=1 используется более широко и не даёт нового права.

Окно показывает текущего менеджера и активных сотрудников для выбора. Если связан документ Контура, показывается пояснение о смене локального менеджера. Если у документа есть другие связи, выводятся номера этих счетов и требуется отдельное подтверждение. Остальные счета Voovi не меняются.

## Хранение
- Все действующие строки выбранного schet.rand получают новый schet.kto.
- Связанный существующий bills получает created_by. Идентификаторы ManagerId/CreateManagerId внешнего биллинга не меняются; вызовов внешнего API нет.
- Номер ns, состав, оплаты и начисленная ЗП не меняются.
- В aktivn записываются счёт, старый/новый менеджер и пользователь, выполнивший действие.
- Операция использует транзакцию InnoDB и блокировки строк; при ошибке журнала изменения откатываются. Устаревшее подтверждение отклоняется, повторное одинаковое сохранение не создаёт вторую запись.
- Пока документ draft/sending/unknown, смена откладывается до окончания создания.

## Файлы
- voovi.ru/invoice_manager.php — проверка роли, снимок связей и согласованная запись.
- voovi.ru/schetkto.php — авторизованный GET для окна, POST с проверкой токена для сохранения. Прежний GET с lico больше не изменяет данные; его интерфейс и раньше был закомментирован.
- voovi.ru/invoice_manager_modal.php, js/invoice-manager.js — окно, подтверждение общего документа, защита повторного клика.
- voovi.ru/komnete.php, css/invoice-detail.css — кнопка и оформление.
- s.voovi.ru-api/basic/kontur_automation/reconcile.py — признаком отправленного запроса служит request_hash; назначенный локально created_by импортированного счёта не включает проверки исходящего запроса.

## Проверки
- PHP tests/invoice-manager.test.php в отдельной voovi_invoice_manager_test: роль, несколько строк, неизменность номера, общий документ, обязательное подтверждение, сохранение менеджера другого счёта, идемпотентность, устаревший снимок, откат при сбое журнала.
- API basic.kontur.tests: 81 тест пройден, включая новый случай назначенного локально менеджера импортированного документа и прежние отказы чужих реквизитов отправленного счёта.
- PHP lint и JS syntax пройдены. Окно проверено в браузере на компьютере и 390 px. На рабочем локальном счёте смена не выполнялась; запись проверена только на тестовых данных. Production не изменялся.
