# Отбор счетов к продлению — 03.11.2026

В «Продления» допускаются только активные исходные счета с `del=0`, `cher=0`,
`otk=0`, без даты отказа и с обоими признаками `prodlens=0 AND prodlenks=0`.
Для всех трёх типов любой признак «продлено» исключает исходный счёт целиком.

Период проверяется по типу: для сертификата — `dataprod`, для поставки —
`datasert`, для «Сер/Пос» — любая из этих дат. Исправлены перепутанные подписи
частей при отображении дат.

Исходный счёт исключается, если уже выставлен следующий активный счёт или
отказной клон: тот же клиент, `shetold = ns` исходного счёта, другой `rand`,
`del=0`, `otk=0`. Оплата и дата следующего счёта не влияют на исключение.
Черновики и удалённые счета сами по себе не закрывают ожидание продления.
Условия общие для счётчика и списка.

При возвращении из другой вкладки список сбрасывается и счётчики обновляются.
Кнопка «Текущий месяц» подставляет первый и последний день месяца, обновляет
список и оставляет оба поля даты доступными для редактирования.

Проверены все четыре сочетания признаков для каждого из трёх типов,
неоплаченные продления вне периода, отказные клоны, удалённые счета, черновики,
совпадающие номера у разных клиентов, отказ на источнике, точные границы периода
и статистика многопозиционных отказов. SQL-тест работает только в отдельной
одноразовой `voovi_schet_identity_test_*` БД. JS-проверки покрывают начальный
период, смену организации, устаревшие ответы и обновление при возвращении.

Изменения схемы БД и корректировки рабочих счетов для выпуска не требуются.
