# Уведомления VK

Уведомления Django API, задач Контура, отчётов и аналитики отправляются в VK. Общий получатель, указанный пользователем: **3736149**.
Использован существующий токен сообщества из настроек проекта; секреты в документе не приводятся.

## Общая реализация

`utils.vk.VKClient` в Django API отправляет текст и документы. Активные вызовы
складских задач, ошибок Диадока, проверки счетов, статистики Контура и Excel-отчётов
используют этот отправитель. Большие сообщения разбиваются на части; каждый запрос
messages.send содержит отдельный random_id. Сеть ограничена тайм-аутами,
редиректы и автоматические повторы отправки отключены. Ответ с ошибкой VK не считается успехом.

Файлы: docs.getMessagesUploadServer → загрузка → docs.save → messages.send с вложением.
Локальный отчёт удаляется только после подтверждённой отправки, если это запросил вызывающий код.
Ошибка загрузки или отправки сохраняет файл. Ошибка последующей локальной очистки не вызывает
повторную отправку уже доставленного отчёта.

Аналитика передаёт уведомления существующему авторизованному API Voovi `/api/v1/send-massege`.
VK-транспорт не дублируется в аналитике. Этот API принимает ключ `vk_to_whom`.
Отправка электронной почты сохранена. Все сообщения направляются общему получателю;
дублирование по списку старых имён не выполняется.

## Настройки общего env

- `VK_ACCESS_TOKEN` — существующий токен сообщества.
- `VK_NOTIFICATION_PEER_ID=3736149` — получатель всех уведомлений.
- `VK_PROXY_API_TOKEN` — токен пользователя Voovi для уведомлений из аналитики.
- `VK_VOOVI_API_URL` — внутренний адрес Django API, по умолчанию `http://svoovi-api:8000`.

Задачи Контура по-прежнему требуют `--notifications`. Их расписание и курсор не менялись.
Настройки VK внесены в общие local.env и prod.env. Изменения production-сервера и его cron этим не выполняются.

## Проверка

Чтение `messages.isMessagesFromGroupAllowed` подтвердило: получатель 3736149 разрешил
сообщения существующему сообществу. Проверочные сообщения и документы при разработке
не отправлялись. Текст, разбиение, ошибки, файлы, отправка через API и адаптер аналитики
проверены автономными тестами с заглушками HTTP.
Проверены исходники API, аналитики и шаблоны интерфейса: используется только VK.

Методы сверены с [официальной схемой VK messages](https://github.com/VKCOM/vk-api-schema/blob/master/messages/methods.json)
и [официальной схемой VK docs](https://github.com/VKCOM/vk-api-schema/blob/master/docs/methods.json).
