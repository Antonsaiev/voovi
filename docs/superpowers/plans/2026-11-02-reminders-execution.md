# Перенос адреса, контактов, брони и звонков

Область: три старые cron-строки; месячный контроль, отчёты, банковские и системные cron не менять.

Решения: сохраняем прежние условия (контакты: вчера, статус65 исключён, отделы10/12/22/24; ноль контактов без письма, один заполняется, несколько — письмо; особый получатель менеджера26; адрес: вчерашние road=1, активные неотгруженные; бронь/звонок: прежние оба message-флага и отсутствие даты оплаты). Группируем по rand, номер берём из ns. Существующий ручной контакт не затираем. Спорные старые условия в этом переносе не переосмысливаем.

Журнал уведомлений — новая отдельная таблица с уникальным хешем события, без изменения финансовых таблиц. SMTP вне транзакции; неопределённую доставку после обрыва автоматически не повторяем. Для автозаполнения контактов — блокировка группы и повторная проверка единственной связи. Dry-run ничего не пишет и не отправляет. Новое расписание при установке выключено; включение только после успешной приёмки и отключения трёх прежних строк.
