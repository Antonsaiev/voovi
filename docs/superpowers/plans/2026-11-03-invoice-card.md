# Invoice Card Implementation Plan

> Execute inline with superpowers:executing-plans.

**Goal:** Устойчивая и удобная адаптивная карточка счёта.
**Architecture:** Существующий PHP сохраняет условные блоки и обработчики. Именованные контейнеры и отдельный CSS заменяют плавающую компоновку карточки, не затрагивая другие страницы.
**Tech Stack:** PHP, Bootstrap 3, jQuery, CSS Grid/Flex.
**Spec:** docs/superpowers/specs/2026-11-03-invoice-card-design.md

## Constraints
Не менять схему БД, бизнес-логику и идентификаторы полей. Проверять локально без финансовых операций; production отдельно.

## Review Focus
Длинные значения, узкие окна, вкладки документов, условные поля разных продуктов, редакторы комментариев не должны расширять страницу или скрывать действия.
