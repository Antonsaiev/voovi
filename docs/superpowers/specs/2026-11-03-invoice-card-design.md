# Переработка карточки счёта

Страница: komnete.php, пример rand=2707620261103. Цель — устойчивая адаптивная компоновка, удобное чтение счёта и доступ к существующим действиям.

## Выбранный подход

Рассмотрены точечное исправление съезжающих элементов и полная переработка представления карточки. Пользователь выбрал полную переработку: единая компоновка и адаптивные блоки. Реализация остаётся в существующих PHP, CSS и JavaScript, без нового интерфейсного фреймворка (выбор исполнителя).

## Представление

1. Компактная шапка: клиент, номера, суммы и статус работы.
2. Документы и действия со счётом — в одном последовательном блоке, таблица с локальной горизонтальной прокруткой при нехватке места.
3. Рабочая область: комментарии, ЭЦП и дополнительные сведения; соседняя колонка — контактное лицо, агент, продление и документы. На узких экранах — одна колонка в логичном порядке.
4. Одинаковые размеры полей, подписи над узкими полями, ровные отступы, хорошо различимые заголовки. Длинные значения переносятся, таблицы не расширяют страницу.
5. Состав Контура остаётся сворачиваемым. Все нынешние действия доступны; вторичные действия визуально компактны.

## Ограничения

Меняется представление, без изменения схемы базы, сумм, оплаты, ЗП, отгрузки, авторизации и бизнес-правил. Сохраняются ID и имена полей, параметры ссылок, обработчики событий и существующие запросы. Условные блоки разных продуктов учитываются при правке разметки.

## Проверка

Визуальная проверка указанного счёта и другого продукта на широком и узком окне. Проверка отсутствия переполнения, раскрытия состава/истории, вкладок документов и переключателей без финансовых записей. PHP lint и подходящие имеющиеся тесты интерфейса. Выкладка production — только отдельным действием после локальной проверки.

## Второй проход: frontend-design
Рабочая карточка счета для менеджера Савоира. Главная задача — быстро узнать счет, увидеть документы и изменить рабочие поля.

Токены: текст/шапка #173747, вторичный текст #526875, Контур #167267, фон #eff3f5, бумага #ffffff, разделители #d8e1e6. Шрифт Segoe UI с локальным Verdana fallback, заголовки 22–24 px, разделы 17 px, значения 14–15 px. Суммы имеют табличные цифры.

Компоновка с выравниванием влево:
```
[Клиент                                           ]
[Счет / реквизиты                    Статус, история]
[Контур                                            ]
[Вкладки документов                                ]
[Документы и суммы                                 ]
[Маркировка                                        ]
[Контакт / параметры] [Комментарий / история        ]
[                  ] [ЭЦП / дополнительные поля    ]
```
Самокритика первого варианта: одинаковые скругленные панели и вложенные рамки скрывали иерархию. Во втором проходе одна выразительная шапка объединяет клиента и номер, вкладки используют подчеркивание, внутренние панели ЭЦП/комментария заменены спокойными разделителями. Нет декоративных градиентов, анимаций или новых внешних шрифтов. Сохранены все поля и действия; финансовая логика не меняется.
